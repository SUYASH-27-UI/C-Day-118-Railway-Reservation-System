# C Day 118 – Railway Reservation Management System

## Project Description
A menu-driven railway reservation application developed in C. It allows users to reserve seats, search bookings, check seat availability and cancel tickets.

## Features
- 20-seat reservation system
- Generate unique booking IDs
- Store passenger name and age
- Display seat availability
- Search booking by ID
- Cancel existing tickets

## Technologies Used
- C Programming
- Structures
- Arrays
- Functions
- Searching

## File
`railway.c`

## How to Compile
`gcc railway.c -o railway`

## How to Run
Windows: `railway.exe`

Linux: `./railway`

## Concepts Learned
Structures, arrays, functions, searching and menu-driven programming.

## Note
This educational version stores booking records in memory. All records are cleared when the program exits.
